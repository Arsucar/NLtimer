# 模块详解

## app 模块

**职责**：Android Application 入口，全局 Scaffold、导航注册、Hilt 初始化。

**关键类**：

| 类 | 文件 | 说明 |
|---|---|---|
| `MainActivity` | `app/.../MainActivity.kt` | 单 Activity 入口，加载主题并调用 NLtimerApp |
| `NLtimerApplication` | `app/.../NLtimerApplication.kt` | `@HiltAndroidApp`，Debug 构建时通过反射初始化 DebugInitializer |
| `NLtimerApp` | `app/.../NLtimerApp.kt` | 顶层 Composable，创建 NavController 并调用 Scaffold |
| `NLtimerScaffold` | `app/.../NLtimerScaffold.kt` | 全局布局容器：抽屉、顶栏、底栏、导航宿主、布局切换弹窗 |
| `NLtimerRoutes` | `app/.../navigation/NLtimerRoutes.kt` | 路由常量（`HOME`, `STATS`, `SETTINGS` 等） |
| `NLtimerNavHost` | `app/.../navigation/NLtimerNavHost.kt` | NavHost 路由注册表，绑定各 feature 的 Route composable |

**app/component/ 组件**：

| 组件 | 说明 |
|---|---|
| `AppBottomNavigation` | 标准 NavigationBar 底栏 |
| `AppDrawer` | 侧边抽屉（ModalNavigationDrawer） |
| `AppTopAppBar` | 固定式顶栏 |
| `AppCollapsedTopAppBar` | 折叠式顶栏（enterAlwaysScrollBehavior） |
| `AppFloatingBottomBar` | 浮动底栏 |
| `AppCenterFabBottomBar` | 居中 FAB + 可拖拽设置底栏 |
| `RouteSettingsPopup` | 布局切换弹出面板 |

## core:data 模块

**职责**：数据库（Room）、DAO、Entity、领域模型、Repository 接口与实现、UseCase、数据导入导出、用户偏好（SettingsPrefs）。

### 子包结构

| 子包 | 说明 |
|---|---|
| `database/entity/` | 6 个 Room Entity |
| `database/dao/` | 4 个 DAO 接口 |
| `database/migration/` | 9 个迁移脚本（v3→v12） |
| `model/` | 领域模型（Activity, Behavior, Tag, ActivityGroup 等） |
| `repository/` | 仓库接口 |
| `repository/impl/` | 仓库实现类 |
| `usecase/` | UseCase（AddActivity, AddBehavior, AddTag, Export, Import） |
| `di/` | Hilt Module（DatabaseModule, DataModule, ServiceModule） |

### 关键接口

**ActivityRepository**（`repository/ActivityRepository.kt`）：
- `getAllActive()`, `getAll()`, `getAllGroups()`, `search()`, `getById()`, `getByName()`, `insert()`, `update()`, `setArchived()`

**BehaviorRepository**（`repository/BehaviorRepository.kt`）：
- `getByDayRange()`, `getCurrentBehavior()`, `getHomeBehaviors()`, `insert()`, `setEndTime()`, `setStatus()`, `endCurrentBehavior()`, `completeCurrentAndStartNext()`, `settleDay()`, `updateBehavior()`, `updateTagsForBehavior()`

**TagRepository**（`repository/TagRepository.kt`）：
- `getAllActive()`, `getByCategory()`, `getByActivityId()`, `getDistinctCategories()`, `setActivityTagBindings()`

**SettingsPrefs**（`SettingsPrefs.kt`）：
- `getThemeFlow()`, `updateTheme()`, `getDialogConfigFlow()`, `updateDialogConfig()`, `getHomeLayoutConfigFlow()`, `getTimeLabelConfigFlow()`, `getDisplayColorConfigFlow()`

## core:designsystem 模块

**职责**：主题系统、设计 Token、通用可复用组件。

### 子包结构

| 子包 | 说明 |
|---|---|
| `theme/` | 主题配置（Theme, ThemeConfig, AppTheme, PaletteStyle, HomeLayout, BottomBarMode, TopBarMode 等） |
| `component/` | 通用 UI 组件（30+ 个文件） |
| `form/` | 表单组件 |
| `icon/` | 图标资源 |
| `debug/` | Debug 专用组件 |

### 核心类型

| 类型 | 文件 | 说明 |
|---|---|---|
| `Theme` | `theme/ThemeConfig.kt` | 全局主题配置（appTheme, paletteStyle, seedColor, font, homeLayout 等） |
| `NLtimerTheme` | `theme/Theme.kt` | Composable 主题入口，通过 DynamicMaterialTheme 注入 |
| `LocalTheme` | `theme/Theme.kt` | CompositionLocal，子组件通过 `LocalTheme.current` 读取 |
| `HomeLayout` | `theme/HomeLayout.kt` | 首页布局枚举：`GRID`, `TIMELINE_REVERSE`, `LOG`, `MOMENT` |
| `BottomBarMode` | `theme/BottomBarMode.kt` | 底栏模式：`STANDARD`, `FLOATING`, `CENTER_FAB` |
| `TopBarMode` | `theme/TopBarMode.kt` | 顶栏模式：`PINNED`, `COLLAPSED` |
| `AppTheme` | `theme/AppTheme.kt` | 亮暗模式：`LIGHT`, `DARK`, `SYSTEM` |
| `PaletteStyle` | `theme/PaletteStyle.kt` | 调色板风格（9 种） |

## core:tools 模块

**职责**：工具注册表（ToolRegistry）、工具定义接口（ToolDefinition）、计时工具、匹配工具。

### 关键类

| 类 | 文件 | 说明 |
|---|---|---|
| `ToolDefinition` | `ToolDefinition.kt` | 工具接口：name, description, category, accessLevel, parameters, execute() |
| `ToolRegistry` | `ToolRegistry.kt` | `@Singleton` 工具注册表，Hilt Multibinding 收集，提供 executeTool() |
| `ToolResult` | `ToolResult.kt` | 工具执行结果（Success / Error） |
| `ToolError` | `ToolError.kt` | 错误类型（NotFound, TimeoutError, ValidationError, InternalError） |

### 子包

| 子包 | 说明 |
|---|---|
| `timing/` | 计时相关工具 |
| `match/` | 活动关键词匹配工具 |
| `library/` | 工具库 |
| `di/` | 工具 DI Module |

---
