## core:designsystem/theme/（主题与 Token）

### 核心入口

| 组件 | 说明 |
|------|------|
| `NLtimerTheme` | Composable 主题入口，使用 DynamicMaterialTheme 生成动态调色板 |
| `LocalTheme` | `staticCompositionLocalOf<Theme>`，全局主题配置读取入口 |
| `LocalImmersiveTopPadding` | 沉浸式顶栏顶部留白 |

### 枚举与配置

| 类型 | 枚举值 | 说明 |
|------|--------|------|
| `AppTheme` | `LIGHT`, `DARK`, `SYSTEM` | 亮暗模式 |
| `PaletteStyle` | `TONALSPOT`, `NEUTRAL`, `VIBRANT`, `EXPRESSIVE`, `RAINBOW`, `FRUITSALAD`, `MONOCHROME`, `FIDELITY`, `CONTENT` | 调色板风格 |
| `HomeLayout` | `GRID`, `TIMELINE_REVERSE`, `LOG`, `MOMENT` | 首页布局 |
| `BottomBarMode` | `STANDARD`, `FLOATING`, `CENTER_FAB` | 底栏模式 |
| `TopBarMode` | `PINNED`, `COLLAPSED` | 顶栏模式 |
| `Fonts` | `FIGTREE` 等 | 字体 |
| `DisplayColorMode` | — | 图标/标签颜色显示模式 |
| `StyleConfig` | — | 样式配置 |
| `Expressiveness` | — | 表现力配置 |
