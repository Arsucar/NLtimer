# 导航与路由

## 路由常量

定义在 `app/.../navigation/NLtimerRoutes.kt`。

### 主导航路由（底栏可见）

| 常量 | 路由字符串 | 对应页面 |
|------|-----------|---------|
| `HOME` | `"home"` | 首页 |
| `STATS` | `"stats"` | 统计 |
| `CATEGORIES` | `"categories"` | 分类管理 |
| `MANAGEMENT_ACTIVITIES` | `"management_activities"` | 活动管理 |
| `SETTINGS` | `"settings"` | 设置 |

| 常量 | 路由字符串 | 来源 |

| `BEHAVIOR_MANAGEMENT` | `"behavior_management"` | 数据管理 → 行为管理 |
| `TAG_MANAGEMENT` | `"tag_management"` | 活动管理内跳转 |
| `AI_INTER` | `"ai_inter"` | AI 交互（实验性） |
| `AI_PROVIDER_CONFIG` | `"ai_provider_config"` | AI 配置 |

### 路由分类

```kotlin
// 主要导航（底栏 + 抽屉可见）
PRIMARY_ROUTES = setOf(HOME, STATS, CATEGORIES, MANAGEMENT_ACTIVITIES, SETTINGS)

// 全屏子页面（隐藏底栏，显示返回按钮）
SETTINGS_FULLSCREEN_ROUTES = setOf(THEME_SETTINGS, DIALOG_CONFIG, BEHAVIOR_MANAGEMENT, ...)
```

## 导航流程

### 主导航

```
NLtimerScaffold
    └── NLtimerNavHost (startDestination = "home")
         ├── composable("home")      → HomeRoute
         ├── composable("stats")     → StatsRoute
         ├── composable("categories") → CategoriesRoute
         ├── composable("management_activities") → ActivityManagementRoute
         ├── composable("settings")  → SettingsRoute
         └── ... 其他路由
```

### 设置页面导航树

```
设置 (settings)
 ├── → 主题配置 (theme_settings)      slideInHorizontally
 ├── → 弹窗配置 (dialog_config)       slideInHorizontally
 ├── → 首页布局配置 (home_layout_config) slideInHorizontally
 ├── → 调色板 (color_palette)         slideInHorizontally
 └── → 数据管理 (data_management)     slideInHorizontally
      └── → 行为管理 (behavior_management) slideInHorizontally
```

### 活动管理导航

```
活动管理 (management_activities)
 └── → 标签管理 (tag_management)      (onNavigateBack)
```

### Debug 路由

Debug 模块通过 `debugRoutes` 变量动态注入路由：

```kotlin
// NLtimerNavHost.kt 末尾
internal var debugRoutes: (NavGraphBuilder.() -> Unit)? = null
// Release 构建中此变量保持 null
```

## 页面转场动画

- **全屏子页面**：使用 `slideInHorizontally` / `slideOutHorizontally` 水平滑动
- **主导航页面**：无自定义动画，使用 Navigation Compose 默认行为
- **返回动画**：反向滑动（`popEnterTransition` / `popExitTransition`）

## 底栏与顶栏行为

`NLtimerScaffold` 根据当前路由决定 UI 结构：

| 条件 | 顶栏 | 底栏 |
|------|------|------|
| 主导航路由 | 自定义顶栏（标题 + 布局切换） | 标准/浮动/居中FAB 底栏 |
| 全屏子页面（非 AI） | `TopAppBar` + 返回按钮 | 隐藏 |
| AI 交互页面 | 自定义顶栏 + 返回按钮 | 隐藏 |

## 导航模式

```kotlin
// 底栏/抽屉导航（saveState + restoreState）
fun navigateToRoute(route: String) {
    navController.navigate(route) {
        popUpTo(navController.graph.startDestinationId) { saveState = true }
        launchSingleTop = true
        restoreState = true
    }
}
```
