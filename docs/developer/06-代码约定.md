# 代码约定

## 项目结构约定

### 模块组织

```
feature/<feature_name>/
    src/main/java/com/nltimer/feature/<feature_name>/
        model/        ← UI 状态模型
        ui/           ← Route Composable + Screen
        viewmodel/    ← ViewModel
        di/           ← Hilt Module（可选）
        match/        ← 匹配策略（可选）
        export/       ← 导出逻辑（可选）

core/<core_name>/
    src/main/java/com/nltimer/core/<core_name>/
        database/     ← Room Entity + DAO + Migration
        model/        ← 领域模型
        repository/   ← 仓库接口
        repository/impl/ ← 仓库实现
        usecase/      ← UseCase
        di/           ← Hilt Module
        ...           ← 模块特有子包
```

### app 模块

```
app/src/main/java/com/nltimer/app/
    navigation/     ← 路由常量 + NavHost
    component/      ← 全局 UI 组件（顶栏、底栏、抽屉）
    viewmodel/      ← 全局 ViewModel（DrawerViewModel）
    di/             ← Application 级 DI
    experimental/   ← 实验性功能（AI Inter）
```

## 命名规范

### 文件命名

| 类型 | 格式 | 示例 |
|------|------|------|
| Entity | `*Entity.kt` | `ActivityEntity.kt` |
| DAO | `*Dao.kt` | `ActivityDao.kt` |
| Repository 接口 | `*Repository.kt` | `BehaviorRepository.kt` |
| Repository 实现 | `同接口名`，放在 `impl/` 子包 | `BehaviorRepositoryImpl.kt` |
| UseCase | `*UseCase.kt` | `AddBehaviorUseCase.kt` |
| ViewModel | `*ViewModel.kt` | `HomeViewModel.kt` |
| 领域模型 | 直接用领域名 | `Activity.kt`, `Behavior.kt` |
| 导航 | `*Routes.kt` + `*NavHost.kt` | `NLtimerRoutes.kt` |
| 组件 | PascalCase，描述性名称 | `BehaviorDetailDialog.kt` |
| 迁移 | `MigrationXToY.kt` | `Migration11To12.kt` |

### 类命名

| 类型 | 格式 | 示例 |
|------|------|------|
| Composable 函数 | PascalCase | `HomeRoute`, `AddBehaviorSheet` |
| ViewModel | `*ViewModel` | `ThemeSettingsViewModel` |
| Route 函数 | `*Route` | `StatsRoute`, `SettingsRoute` |
| Screen 函数 | `*Screen` | `StatsScreen`, `SettingsScreen` |
| Repository 接口 | `*Repository` | `TagRepository` |
| Hilt Module | `*Module` | `DatabaseModule`, `DataModule` |

### 变量命名

- `Flow` 类型变量不加后缀：`getAllActive()` 返回 `Flow`，函数名直接表达含义
- 同步版本函数加 `Sync` 后缀：`getAllActiveSync()`, `getByTimeRangeSync()`
- 状态变量使用 `State` 后缀或 `UiState`：`HomeUiState`, `MomentFilterState`

### 常量

- 路由字符串常量定义在 `NLtimerRoutes` object 中
- 数据库表名使用 snake_case 字符串：`"activities"`, `"behavior_tag_cross_ref"`

## 设计模式

### MVVM + 单 Activity

```
Activity (MainActivity)
    └── Composable 树
         └── Route Composable
              └── ViewModel (hiltViewModel())
                   └── Repository 接口
                        └── Repository 实现
                             └── Room DAO
```

- 每个页面由一个 `*Route` composable 暴露给导航
- Route 内通过 `hiltViewModel()` 获取 ViewModel
- ViewModel 通过 Repository 接口访问数据
- UI 状态通过 `StateFlow` / `collectAsStateWithLifecycle()` 观察

### Repository 模式

```kotlin
// 接口定义在 repository/ 目录
interface BehaviorRepository { ... }

// 实现定义在 repository/impl/ 目录
class BehaviorRepositoryImpl @Inject constructor(
    private val behaviorDao: BehaviorDao,
    ...
) : BehaviorRepository { ... }
```

### UseCase 模式

复杂业务逻辑封装为 UseCase：

```kotlin
class AddBehaviorUseCase @Inject constructor(
    private val behaviorRepository: BehaviorRepository,
) {
    suspend operator fun invoke(behavior: Behavior, tagIds: List<Long>): Long {
        return behaviorRepository.insert(behavior, tagIds)
    }
}
```

### Hilt 依赖注入

- Application 类标记 `@HiltAndroidApp`
- Activity 标记 `@AndroidEntryPoint`
- ViewModel 使用 `@HiltViewModel` + `@Inject constructor`
- Repository 实现通过 `@Inject` + `@Singleton` 注册
- 工具通过 `@IntoSet` 多绑定注入 `ToolRegistry`
- DI Module 使用 `@Module` + `@InstallIn`

### CompositionLocal 模式

跨组件传递主题/状态：

```kotlin
val LocalTheme = staticCompositionLocalOf { Theme() }
val LocalMomentFilterState = compositionLocalOf { ... }
val LocalVisibleDateLabel = compositionLocalOf { ... }
val LocalImmersiveTopPadding = compositionLocalOf { 0.dp }
```

### Entity ↔ Model 转换

领域模型通过伴生对象的 `fromEntity()` 和 `toEntity()` 进行双向转换：

```kotlin
data class Activity(...) {
    fun toEntity() = ActivityEntity(...)
    companion object {
        fun fromEntity(entity: ActivityEntity) = Activity(...)
    }
}
```

### Debug 模块动态加载

Release 构建通过 ProGuard 移除 Debug 代码，运行时通过反射探测：

```kotlin
// NLtimerApplication.kt
Class.forName("com.nltimer.app.DebugInitializer")
    .getMethod("init").invoke(null)

// NLtimerNavHost.kt
internal var debugRoutes: (NavGraphBuilder.() -> Unit)? = null
```

## 编码约定

- **语言**：全部使用 Kotlin，UI 使用 Jetpack Compose
- **不可变数据**：领域模型使用 `@Immutable` 注解，UI 状态使用 `data class`
- **协程**：数据库操作使用 `suspend` 函数，UI 观察使用 `Flow`
- **版本管理**：所有依赖版本集中在 `gradle/libs.versions.toml`
- **共享构建逻辑**：放在 `buildSrc/` 的预编译脚本插件中
- **Debug 隔离**：Debug 专用代码放入 `feature:debug` 或 `core:debugui`，通过 `debugImplementation` 引入
