# 架构概览

## 技术栈

| 项 | 值 |
|---|---|
| 语言 | Kotlin 2.3.21 |
| UI 框架 | Jetpack Compose + Material 3 |
| 构建 | AGP 9.2.0, compileSdk/targetSdk 36, minSdk 31 |
| 依赖注入 | Hilt + KSP |
| 数据库 | Room 2.7.1, 版本 12, 6 张表 |
| 导航 | Navigation Compose 2.9.0 |
| 序列化 | Kotlinx Serialization 1.8.1 |
| 偏好存储 | DataStore Preferences |
| 主题引擎 | MaterialKolor（动态调色板） |
| 版本 | 0.1.5 (versionCode 105) |
| 包名 | `com.nltimer.app` |

## 分层架构

```
┌─────────────────────────────────────────────────────┐
│  app 模块（Android Application）                      │
│  MainActivity → NLtimerApp → NLtimerScaffold          │
│  全局导航 (NLtimerNavHost) + 抽屉 + 底栏 + 顶栏        │
├─────────────────────────────────────────────────────┤
│  feature:* 模块（UI 层）                               │
│  每个 feature 暴露 Route composable                    │
│  内含 viewmodel / ui / model 子包                      │
├─────────────────────────────────────────────────────┤
│  core:* 模块（共享能力层）                              │
│  designsystem → 主题、组件、设计 token                  │
│  behaviorui   → 行为弹窗、选择器等跨页面 UI             │
│  data         → 数据库、Repository、UseCase、模型       │
│  tools        → 工具注册表、计时、匹配                   │
│  debugui      → Debug 专用 UI                         │
├─────────────────────────────────────────────────────┤
│  数据持久化                                            │
│  Room (6 表) + DataStore Preferences                  │
└─────────────────────────────────────────────────────┘
```

## 模块依赖方向

```
app
 ├── feature:home          ← core:data, core:designsystem, core:behaviorui, core:tools
 ├── feature:stats         ← core:data, core:designsystem
 ├── feature:settings      ← core:data, core:designsystem
 ├── feature:categories    ← core:data, core:designsystem
 ├── feature:management_activities ← core:data, core:designsystem
 ├── feature:tag_management ← core:data, core:designsystem
 ├── feature:behavior_management ← core:data, core:designsystem
 ├── feature:debug         ← core:data, core:debugui (仅 debugImplementation)
 ├── core:designsystem     ← 无内部依赖
 ├── core:data             ← core:designsystem (Theme 类型)
 ├── core:behaviorui       ← core:data, core:designsystem
 ├── core:tools            ← core:data
 └── core:debugui          ← core:data
```

**依赖规则**：`app → feature → core`，feature 之间不互相依赖。

## 数据流向

### 核心数据流（行为计时）

```
用户操作 UI
    ↓
ViewModel (feature 模块)
    ↓ 调用
Repository 接口 (core:data/repository/)
    ↓ 委托
Repository 实现 (core:data/repository/impl/)
    ↓ 操作
Room DAO (core:data/database/dao/)
    ↓ SQL
SQLite 数据库
```

### 主题配置数据流

```
用户修改主题设置
    ↓
ThemeSettingsViewModel
    ↓ 调用
SettingsPrefs (接口)
    ↓ 委托
SettingsPrefsImpl (DataStore Preferences)
    ↓ Flow<Theme>
NLtimerTheme (CompositionLocal 注入)
    ↓
所有子组件通过 LocalTheme.current 读取
```

### 导航数据流

```
NLtimerScaffold
    ├── 创建 NavController
    ├── 判断当前路由 (currentRoute)
    ├── 选择顶栏/底栏样式
    └── NLtimerNavHost (注册所有路由)
         ├── HomeRoute
         ├── StatsRoute
         ├── SettingsRoute → 子页面路由
         └── 其他 feature Route
```
