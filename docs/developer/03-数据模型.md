# 数据模型

## 数据库概览

- **数据库类**：`NLtimerDatabase`（`core/data/.../database/NLtimerDatabase.kt`）
- **版本**：12
- **表数量**：6
- **schema 导出**：关闭（`exportSchema = false`）

## 实体关系图

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────┐
│ activity_    │     │ activity_tag_    │     │              │
│ groups       │────→│ binding          │←────│   tags       │
│              │ 1:N │                  │ N:1 │              │
└──────────────┘     └──────────────────┘     └──────────────┘
       │                                          │
       │ 1:N (groupId)                            │ N:M
       ↓                                          ↓
┌──────────────┐     ┌──────────────────┐
│ activities   │────→│ behaviors        │
│              │ 1:N │                  │
└──────────────┘     └──────────────────┘
                            │
                            │ N:M
                            ↓
                     ┌──────────────────┐
                     │ behavior_tag_    │
                     │ cross_ref        │
                     └──────────────────┘
                            │
                            ↓
                     ┌──────────────┐
                     │   tags       │
                     └──────────────┘
```

## 实体详情

### activities（活动表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `Long` PK 自增 | 主键 |
| `name` | `String` UNIQUE | 活动名称 |
| `iconKey` | `String?` | 图标键 |
| `keywords` | `String?` | 关键词（逗号分隔，用于备注匹配） |
| `groupId` | `Long?` FK → activity_groups.id | 所属分组 |
| `isPreset` | `Boolean` | 是否预设活动 |
| `isArchived` | `Boolean` | 是否已归档 |
| `archivedAt` | `Long?` | 归档时间戳 |
| `color` | `Long?` | 颜色值 |
| `usageCount` | `Int` | 使用次数 |
| `createdAt` | `Long` | 创建时间 |
| `updatedAt` | `Long` | 更新时间 |

**索引**：`name`(unique), `isArchived`, `groupId`

### activity_groups（活动分组表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `Long` PK 自增 | 主键 |
| `name` | `String` UNIQUE | 分组名称 |
| `sortOrder` | `Int` | 排序权重 |
| `isArchived` | `Boolean` | 是否已归档 |
| `archivedAt` | `Long?` | 归档时间戳 |
| `createdAt` | `Long` | 创建时间 |

**索引**：`name`(unique)

### tags（标签表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `Long` PK 自增 | 主键 |
| `name` | `String` UNIQUE | 标签名称 |
| `color` | `Long?` | 颜色值 |
| `iconKey` | `String?` | 图标键 |
| `category` | `String?` | 分类名称 |
| `priority` | `Int` | 优先级（越高越靠前） |
| `usageCount` | `Int` | 使用次数 |
| `sortOrder` | `Int` | 排序权重 |
| `isArchived` | `Boolean` | 是否已归档 |
| `archivedAt` | `Long?` | 归档时间戳 |
| `keywords` | `String?` | 关键词 |

**索引**：`name`(unique), `isArchived`, `category`

### behaviors（行为记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `Long` PK 自增 | 主键 |
| `activityId` | `Long` FK → activities.id (CASCADE) | 关联活动 |
| `startTime` | `Long` | 开始时间戳 |
| `endTime` | `Long?` | 结束时间戳（null 表示进行中） |
| `status` | `String` | 状态：`pending` / `active` / `completed` |
| `note` | `String?` | 备注 |
| `pomodoroCount` | `Int` | 番茄钟计数 |
| `sequence` | `Int` | 排序权重（用于待办列表排序） |
| `estimatedDuration` | `Long?` | 预估时长（毫秒） |
| `actualDuration` | `Long?` | 实际时长（毫秒） |
| `achievementLevel` | `Int?` | 成就等级 |
| `wasPlanned` | `Boolean` | 是否为计划行为 |

**索引**：`activityId`, `(startTime, sequence)`, `status`, `(startTime, status)`

**外键**：`activityId` → `activities.id`，ON DELETE CASCADE

### activity_tag_binding（活动-标签关联表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `activityId` | `Long` PK FK → activities.id (CASCADE) | 活动ID |
| `tagId` | `Long` PK FK → tags.id (CASCADE) | 标签ID |

### behavior_tag_cross_ref（行为-标签关联表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `behaviorId` | `Long` PK FK → behaviors.id (CASCADE) | 行为ID |
| `tagId` | `Long` PK FK → tags.id (RESTRICT) | 标签ID |

**外键策略差异**：
- 活动删除 → 级联删除关联标签绑定
- 行为删除 → 级联删除关联标签
- 标签删除 → **阻止**（RESTRICT）行为关联中的删除，需先解除关联

## 领域模型

数据库 Entity 通过 `fromEntity()` / `toEntity()` 转换为领域模型：

| 领域模型 | 对应 Entity | 文件 |
|---------|------------|------|
| `Activity` | `ActivityEntity` | `model/Activity.kt` |
| `ActivityGroup` | `ActivityGroupEntity` | `model/ActivityGroup.kt` |
| `Tag` | `TagEntity` | `model/Tag.kt` |
| `Behavior` | `BehaviorEntity` | `model/Behavior.kt` |
| `BehaviorWithDetails` | — | `model/BehaviorWithDetails.kt` |
| `BehaviorNature` | — (enum) | `model/BehaviorNature.kt` |

**BehaviorNature 枚举**：
- `PENDING("pending")` — 待办
- `ACTIVE("active")` — 进行中
- `COMPLETED("completed")` — 已完成

## 导出数据结构

导出格式为 JSON（`ExportData`），包含活动、分组、标签及标签分类：

```kotlin
ExportData {
    version: Int            // 格式版本，当前为 1
    exportedAt: Long        // 导出时间戳
    activities: List<ExportedActivity>
    activityGroups: List<ExportedActivityGroup>
    tags: List<ExportedTag>
    tagCategories: List<String>
}
```

注意：行为记录（behaviors）不包含在导出中，仅导出活动、分组和标签的结构数据。
