# 活动管理

## 概述

活动（Activity）是时间记录的基本分类单位。每个行为必须关联一个活动。

---

## 创建活动

1. 从底栏进入 **活动管理** 页面
2. 点击右下角 **+** 按钮
3. 填写以下字段：
   - **名称**：活动名称（必填）
   - **图标**：选择 Emoji 或 Material Icon
   - **颜色**：自定义活动颜色
   - **分组**：选择所属活动分组（可选）
   - **关键词**：用于备注智能匹配，多个关键词用空格分隔
   - **关联标签**：选择预设关联的标签

也可以在记录行为时快速创建：在活动选择器中**长按**「活动」功能按钮。

---

## 编辑活动

在活动管理页面中，**点击**某个活动即可进入编辑模式，修改名称、图标、颜色等属性。

---

## 活动分组

- 活动可归入不同分组进行归类
- 分组在 `categories` 标签页管理
- 活动选择器中按分组展示活动列表

---

## 归档活动

- 不再使用的活动可以**归档**，归档后不在选择器中显示
- 已归档的活动仍保留在数据中，历史行为记录不受影响
- 可在活动管理页面查看已归档的活动

---

## 关键词与智能匹配

活动设置的关键词用于**备注智能匹配**功能：

1. 在记录行为时输入备注文字
2. 如果备注中包含某活动的关键词，系统自动匹配该活动
3. 也可使用 `@活动名` 指令强制匹配

关键词示例：活动「工作」设置关键词 `work 加班`，则备注中包含「work」或「加班」时自动匹配。
