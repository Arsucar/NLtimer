# 标签系统

## 概述

标签（Tag）是行为记录的第二维度分类，用于在活动基础上进一步细化。一个行为可以关联多个标签。

---

## 创建标签

1. 进入 **分类管理** 页面
2. 切换到 **标签** 标签页
3. 点击 **+** 按钮
4. 填写以下字段：
   - **名称**：标签名称（必填）
   - **图标**：选择 Emoji 或 Material Icon
   - **颜色**：自定义标签颜色
   - **分类**：选择标签所属分类（可选）
   - **优先级**：排序权重，数字越大越靠前
   - **关键词**：用于备注智能匹配

也可以在记录行为时快速创建：在标签选择器中**长按**「标签」功能按钮。

---

## 标签分类

- 标签可归入不同分类（如「工作」、「学习」、「生活」）
- 分类在 `categories` 页面管理
- 标签选择器中按分类展示标签列表

---

## 标签与活动的关系

- 标签和活动是**多对多**关系
- 一个活动可以预设关联多个标签
- 一个行为记录可以选择多个标签
- 标签在行为记录时可自由添加/移除

---

## 智能匹配

标签也支持关键词匹配：

- 备注中包含标签关键词时自动选中该标签
- 使用 `#标签名` 指令强制匹配
- 开启「智能识别」后，输入备注会自动触发匹配
