# 设置与个性化

## 概述

设置页面提供五大类配置入口。

---

## 主题配置

### 主题模式
- **亮色** / **暗色** / **跟随系统**

### Material You 动态取色
- 开启后从壁纸提取主题色（Android 12+）
- 关闭后使用自定义种子色

### 种子色
- 非动态取色模式下，通过**取色器**自由选择主题色

### 配色方案
- 提供 9 种调色板风格预览（圆环展示主色/副色/第三色）
- 切换不同配色风格

### AMOLED 纯黑
- 暗色模式下使用纯黑背景，适合 OLED 屏幕

### 字体
- 可选择多种字体，每种字体实时预览

### 栏位模式
- **顶栏模式**：分段按钮切换
- **底栏模式**：标准 / 居中浮动按钮

### 表达力
- 卡片颜色策略
- 图标容器大小
- 计时器排版
- 波浪进度等级

### 样式风格
- 圆角预设 + 自定义滑块（0-4）
- 边框预设 + 自定义滑块（0-3）
- 透明度预设 + 自定义滑块（0-3）
- 「重置为默认」一键恢复

### 其他
- 显示边框开关
- 沉浸式页面（内容延伸至状态栏）

---

## 色板（开发者工具）

展示 Material Design 3 全部 ColorScheme token 的亮/暗色对比色块，长按可复制十六进制颜色值。

---

## 弹窗配置

配置行为添加面板（AddBehaviorSheet）的显示方式：

### 活动区域
- **显示样式**：无/填充/下划线/胶囊/圆角/方块/方框/手绘/虚线（9 种）
- **布局方向**：水平/垂直
- **行数**：步进调节
- **颜色模式**：强调色/活动色

### 标签区域
- 与活动区域相同的配置选项
- 标签为多选

### 其他选项
- **行为选择器**：显示/隐藏三种模式（完成/当前/目标）切换器
- **路径动画**：单向/双向/随机/无/蛆动（5 种）
- **秒数策略**：打开时/确认时（决定时间精度取自哪个时刻）
- **智能识别**：关闭/自动（输入备注后自动匹配活动与标签）

---

## 主页布局配置

分别配置四种布局的参数，各布局参数独立：

| 布局 | 可配参数 |
|------|---------|
| 网格 | 列数、最小行高、最大格子高度、列间距、格子内边距、图标大小、标签缩放、标签间距、活跃背景透明度 |
| 日志 | 卡片内边距、图标大小、图标间距、标签行间距 |
| 时间线 | 条目间距 |
| 此刻 | 卡片内边距 |

底部提供「恢复全部默认」按钮。
