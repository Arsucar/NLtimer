# 快速上手

## 核心流程

NLtimer 的核心使用流程只有三步：

**创建活动 → 记录行为 → 查看时间线**

---

## 第一步：创建活动

活动是你想记录的事情，比如"阅读"、"运动"、"编程"。

1. 打开应用，进入底栏的**活动管理**页面
2. 点击 **+** 按钮添加新活动
3. 输入活动名称（如"阅读"）
4. 可选：选择图标、颜色、添加关键词
5. 点击确认保存

> **关键词**：为活动设置关键词后，在记录行为时输入备注会自动匹配活动。

---

## 第二步：记录行为

### 开始计时

1. 在首页点击任意活动
2. 系统自动开始计时，顶栏显示当前进行中的行为
3. 完成后点击结束

### 补记行为

1. 在首页点击 **+** 按钮
2. 选择活动
3. 选择行为状态为"已完成"
4. 设置开始和结束时间
5. 可选：添加备注、标签
6. 保存

### 计划行为

1. 在首页点击 **+** 按钮
2. 选择活动
3. 行为状态保持"待办"
4. 保存后，待办行为出现在计划列表中

---

## 第三步：查看时间线

首页提供四种视图查看你的时间使用情况：

| 视图 | 说明 |
|------|------|
| **网格** | 以时间网格展示一天的活动分布 |
| **时间轴** | 从晚到早的反向时间轴 |
| **日志** | 列表形式的行为日志 |
| **此刻** | 聚焦当前进行中的行为 |

通过顶栏的布局标签切换视图模式。

---

## 快捷操作

- **底栏导航**：首页、统计、分类、活动管理、设置
- **侧边抽屉**：从左侧滑出，显示累计统计信息
- **布局切换**：首页顶栏点击布局标签可快速切换视图
- **长按/滑动**：行为卡片支持滑动操作
