# 首页视图

## 概述

首页提供四种布局模式，展示你的行为记录。左右滑动切换布局，顺序循环：网格 → 时间线 → 日志 → 此刻 → 网格。

---

## 网格布局

按时间轴以网格形式展示行为：

- 每行代表一个小时
- 行为以卡片形式填充对应时间格
- 右侧可选**时间侧边栏**，点击可跳转到对应小时

**操作**：
- 点击空白格 → 在该时间段补记行为
- 点击行为卡片 → 查看详情
- 长按行为卡片 → 编辑

---

## 时间线布局

按时间倒序展示行为列表，每天一个分区：

- 显示每个行为的起止时间、活动图标、名称、持续时间、标签、备注
- 空闲时段显示「空闲」标记，带 **+** 按钮可补记

**操作**：
- 点击行为 → 弹出详情对话框
- 长按行为 → 编辑
- 点击空闲 **+** → 在该时段补记

---

## 日志布局

卡片式日志列表，按时间倒序排列：

- 每张卡片展示时间、活动、标签、备注
- 按天分隔

**操作**：
- 点击 → 弹出详情对话框
- 长按 → 编辑
- 无记录时显示「暂无行为记录」

---

## 此刻布局

聚焦当前时刻的行为卡片视图：

- 支持筛选：全部 / 已完成 / 待定
- 支持排序：时间倒序 / 时间正序 / 用时排序

**操作**：
- 点击 → 弹出详情对话框
- 长按 → 编辑

---

## 顶部聚焦卡片

所有布局顶部共享一个**聚焦卡片**：

- **活跃中**：显示正在计时的行为，带实时计时器和脉冲边框，提供「滑动完成」操作
- **待执行**：显示下一个计划行为，带「开始」按钮
- **空闲**：显示「添加」按钮

---

## 底部操作按钮

右下角浮动按钮，根据当前状态变化：

- **无活跃行为**：显示 **+**，点击添加行为；上拉展开选项（完成/目标/当前/自定义）
- **有活跃行为**：显示 **✓**，点击完成行为；上拉展开选项（完成/放弃/特记/自定义）

---

## 布局配置

在每个布局中可打开配置对话框，调整以下参数：

- **网格**：列数、最小行高、最大格子高度、间距、图标大小、标签缩放等
- **日志**：卡片内边距、图标大小、标签行间距
- **时间线**：条目间距
- **此刻**：卡片内边距

每个布局都有**恢复默认**按钮。也可在「设置 → 主页布局配置」中统一定义。
