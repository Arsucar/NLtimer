# 数据管理

## 概述

数据管理页面提供应用数据的导入、导出功能，以及行为记录的详细管理。

---

## 数据导出

支持四种数据范围的导出：

| 范围 | 包含内容 |
|------|---------|
| **总数据** | 所有活动、标签、分类、行为记录 |
| **活动数据** | 活动及其分组 |
| **标签数据** | 标签及其分类 |
| **分类数据** | 活动分组 + 标签分类 |

每种范围提供两种导出方式：
- **导出**：保存为 JSON 文件
- **复制**：复制 JSON 到剪贴板

导出的 JSON 包含元信息（版本号、导出时间、时间范围、筛选条件）和实际数据。

---

## 数据导入

选择数据范围后，提供两种导入方式：
- **导入**：从文件选择 JSON
- **粘贴**：从剪贴板读取 JSON

### 导入预览

导入前会显示预览对话框：
- 总条数、重复条数、新增条数
- 重复项列表（活动名 + 时间范围）
- 需要新建的活动和标签列表
- 可选择重复处理方式

---

## 行为记录管理

从数据管理页面进入，提供完整的行为记录管理功能：

### 时间范围选择

顶部提供快捷时间段：
- 4小时 / 8小时 / 1日 / 3日 / 7日 / 1月 / 1年
- 左右箭头按时间段前后翻页
- 点击日期可打开精确选择器

### 筛选栏

- **活动分组**：按活动组筛选
- **标签分类**：按标签分类筛选
- **状态**：已完成 / 进行中 / 待定
- **搜索**：关键词搜索（搜索活动名、备注、标签）
- **视图切换**：列表视图 / 时间线视图

### 操作

- **点击**行为 → 编辑（打开预填充的行为面板）
- **长按**行为 → 进入多选模式
- 多选模式支持**批量删除**
- 底部显示统计摘要：总条数、已完成数、总时长

### 导入导出

右上角提供导入/导出按钮，可导出当前筛选范围内的行为记录。
