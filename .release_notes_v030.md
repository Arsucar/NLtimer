更新内容:

- 新增 AI 交互实验功能模块，已接入系统设置导航；首页含「提供商配置 / 现有工具 / 调用日志 / 提示词配置 / 测试对话」五个入口
- 提供商配置：可填写 API 地址、路径、密钥、模型名，「获取模型列表」按钮可在线拉取全部模型，配合搜索框直接挑选
- 提示词配置：分别维护「主页备注解析 / 任务自动生成 / 对话助手」三类场景的系统提示词
- 测试对话：流式实时显示回复（含思考过程、工具调用、Markdown 正文），可在生成途中按「停止」中断本次回答，可一键清空历史
- AI 对话接入工具调用能力，本期内置 14 项工具：
  - 计时：开始计时（startBehavior）、结束计时（endBehavior）、查询当前行为（queryCurrentBehavior）、补录行为含冲突提示（recordBehavior）、删除行为（deleteBehavior）、创建目标（createGoal）
  - 活动 / 标签管理：列活动（listActivities）、列标签（listTags）、创建活动（createActivity）、创建标签（createTag）、创建活动分类（createActivityCategory）、声明标签分类（createTagCategory）
  - 匹配检索：精确选择活动与标签（selectActivitiesAndTags）、模糊搜索活动与标签（searchActivitiesAndTags）
- 调用日志：列表按时间倒序展示，附状态、模型、耗时和工具调用标签；详情页可查看时间戳、请求地址、Token 用量、提示词、思考过程、工具调用清单（参数 / 返回 / 成功标记 / 耗时）、响应体与错误信息；支持一键清空全部日志
- 主页网格布局重排：最新时段置顶，每行内从左到右按时间从早到晚排列
- 侧边时间轴顺序与新网格对齐：顶部为较晚小时，底部为较早小时
- 主页底栏精简：移除浮动入口，时间标签开关下沉到底栏菜单，新增时间标签外观设置入口
- 补记交互优化：预计时长输入更顺手，修复跨段时的边界精度问题与时间线空闲段毫秒级重叠

Updates:

- Added an experimental AI module wired into the system settings navigation, exposing five entries: Provider Config, Existing Tools, Call Logs, Prompt Config, and Test Chat
- Provider Config: enter API endpoint, path, key and model name; the "Fetch Models" button pulls the full live model list with a built-in search box for quick picking
- Prompt Config: maintain separate system prompts for three scenarios — note parsing, task generation, and chat assistant
- Test Chat: streamed replies in real time (including reasoning trail, tool calls and Markdown body), with a Stop button to abort mid-stream and a one-tap clear-history action
- AI chat now supports tool calls, with 14 built-in tools this release:
  - Timing: startBehavior, endBehavior, queryCurrentBehavior, recordBehavior (with conflict prompts), deleteBehavior, createGoal
  - Activities / Tags: listActivities, listTags, createActivity, createTag, createActivityCategory, createTagCategory
  - Matching & search: selectActivitiesAndTags (exact token), searchActivitiesAndTags (substring)
- Call Logs: list view in reverse-chronological order with status, model, duration and tool chips; the detail page surfaces timestamp, request URL, token usage, prompt, reasoning trail, full tool-call list (arguments / result / success flag / duration), response body and error message; one-tap clear-all is supported
- Reordered home grid: latest blocks on top, cells within a row run earliest-to-latest
- Side time axis aligned with the new grid: larger hours on top, smaller hours at the bottom
- Simplified home bottom bar: floating entry removed, time-label toggle moved into the bottom menu, time-label appearance settings entry added
- Catch-up entry polish: smoother estimated-duration input, fixed boundary precision and millisecond overlap of idle segments on the timeline
